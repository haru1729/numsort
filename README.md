# numsortコマンド
![test](https://github.com/haru1729/numsort/actions/workflows/test.yml/badge.svg)

numsortは数値列をソートするコマンドです。整数・小数・負数に対応しています。
## インストール手順
Githubからリポジトリをクローンして使用することができます
```bash
git clone https://github.com/haru1729/numsort.git
```

## テスト環境
- Ubuntu 24.04 LTS

## 必要なソフトウェア
- Python
  - テスト済み環境：3.10 ~ 3.14 (追加パッケージ不要)

## 使い方
標準入力から1行の数値列を与えることでソートすることが出来ます。
### 基本的なソート
データを昇順でソートします
```Bash

$ echo "5 0 3 8" | ./numsort
0 3 5 8
$ echo "4 10 -2 -5.5 3" | ./numsort
-5.5 -2 3 4 10
```
### 区切り文字の自動判別
半角スペース、カンマ(,)、セミコロン(;)を自動判別し、入力と同じフォーマットで出力します
```Bash

$ echo "3;8;0;4" | ./numsort
0;3;4;8

$ echo "1,-6,3.5,-0.5" | ./numsort
-6,-0.5,1,3.5
```
## オプション
|オプション|説明|
| :-- | :-- |
|-h, --help|ヘルプメッセージを表示します|
|-r, --reverse|ソートを降順に変更します|
|-d <文字>, <br> --delimiter <文字>|出力データの区切り文字を1文字で指定します<br>(未指定時は入力と同じ文字)|

### オプション使用例
```Bash

#降順ソート
$ echo "4 5 1 0" | ./numsort -r
5 4 1 0

#区切り文字の変更
$ echo "3 5 10 8" | ./numsort -d '|'
3|5|8|10

#オプションの併用
$ echo "5 -2 4.3 8" | ./numsort -rd ','
8,5,4.3,-2
```

## エラー仕様
データやオプション指定に不正があった場合は、標準エラー出力にエラーメッセージを表示し、終了ステータス`1`(コマンドライン引数エラーは`2`)で終了します
- 入力が空
- 数値以外のデータや`NAN`/`INF`が含まれる場合
- 1つの入力に複数の区切りが存在している場合(ex. `"1,2 3"`)
- `-d`オプションに2文字以上の文字列、数字(`0-9`)、符号(`+,-`)、小数点(`.`)
